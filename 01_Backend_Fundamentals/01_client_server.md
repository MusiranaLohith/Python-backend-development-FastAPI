# Client and Server

## Client

A client is a program or device that sends a request to a server.

Examples:
- Web browser
- Mobile application
- Frontend application
- Another backend service

## Server

A server is a program that receives requests, processes them, and sends responses.

## API

An API is an interface that allows different software systems to communicate with each other.

## HTTP

HTTP is the protocol commonly used for communication between clients and web servers.
